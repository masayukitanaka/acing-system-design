クラウドネイティブは、スケーラビリティ、フォールトトレランス、保守性などの非機能要件に対処するアプローチです。Cloud Native Computing Foundationによるクラウドネイティブの定義は次の通りです（https://github.com/cncf/toc/blob/main/DEFINITION.md）。強調のために特定の単語をイタリックにしています:

クラウドネイティブ技術は、組織が、パブリック、プライベート、ハイブリッドクラウドなどの近代的で動的な環境でスケーラブルなアプリケーションを構築・実行できるようにします。コンテナ、サービスメッシュ、マイクロサービス、イミュータブルインフラ、宣言型APIがこのアプローチを体現しています。

これらの技法は、回復力があり、管理可能で、観測可能な、疎結合のシステムを可能にします。堅牢な自動化と組み合わさることで、エンジニアが影響力のある変更を最小限の労苦で、頻繁に、予測可能に行えるようになります。

Cloud Native Computing Foundationは、オープンソースでベンダー中立なプロジェクトのエコシステムを育成・維持することで、このパラダイムの採用を推進することを目指しています。最先端のパターンを民主化し、これらのイノベーションを誰もが利用できるようにします。

本書はクラウドネイティブコンピューティングに関する本ではありませんが、本書を通じてクラウドネイティブの技法（コンテナ、サービスメッシュ、マイクロサービス、サーバーレス関数、イミュータブルインフラまたはInfrastructure as Code、宣言型API、自動化）を活用し、その利点（回復力、管理可能、観測可能、頻繁で予測可能な変更を可能にする）を達成し、関連する概念の資料への参照を含めます。
